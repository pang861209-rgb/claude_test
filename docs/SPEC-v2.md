## 1. 제품 요약

- **한 줄 정의**: 약 먹은 사진을 찍어 인증할 때까지 알림이 계속 오는 개인용(부부용) 복약 인증 iOS 앱.
- **주 사용자**: 아내 — 하루 2회(아침/저녁) 복약, 깜박/미룸 패턴, 알람 무력화 습관, 캐릭터·핑크 감성 선호, 복잡한 UI 기피.
- **보조 사용자**: 남편 — 기록 확인. "먹었어?" 잔소리를 캘린더 확인으로 대체.

## 2. 경험 원칙 (UX 리뷰에서 확정)

1. **해제 비용 > 무시 비용** — 알림을 멈추는 유일한 방법은 사진 인증.
2. **질책 제로** — 실패도 비난 없는 언어로. 지연 완료도 칭찬 톤("늦어도 해냈어요!").
3. **3탭 원칙** — 알림 탭 → 촬영 → 확정, 3터치 이내 완결.
4. **가변 보상** — 랜덤 칭찬 문구 + 파티클 + 햅틱. 보상은 즉시.
5. **예외 흡수** — 일찍 먹는 날(조기 인증), 늦게 먹는 날(지연 뱃지), 자정 넘김(귀속) 모두 자연스럽게.

## 3. 비목표 (변경 없음)

- 서버·계정·클라우드 동기화 없음 (전부 로컬).
- 약 종류별 다중 슬롯 없음 (아침/저녁 2슬롯 고정).
- 보호자 원격 알림 없음 (P2, 서버 필요).
- Android 없음.

## 5. 기능 명세 (전부 구현 완료)

### 5.1 온보딩 + 권한 프라이밍
- 3장: 마스코트 인사 → 동작 방식 설명(알림/촬영/기록) → 시간 설정.
- 시스템 권한 팝업(알림·카메라)은 **"알림 받고 시작하기" 버튼을 누른 뒤에만** 표시.
- `@AppStorage("hasOnboarded")` 게이트.

### 5.2 복약 스케줄
- 슬롯 2개(아침 08:00 / 저녁 20:00 기본), 슬롯별 on/off.
- 변경 시 해당 일자 알림 전체 재생성.

### 5.3 반복 알림 (핵심)
- 슬롯 시각 T부터 **5분 간격 12개**(T ~ T+55) 예약.
- iOS 64개 예약 한도 대응: 앱 foreground 진입 시 미인증이면 **다음 배치 연장** (문구 단계는 seq 누적으로 이어짐).
- 배치 이후 안전망: **희소 후속 알림 3개** (T+90m / T+120m / T+180m, 부담 없는 톤).
- 문구는 순차 단계형: ① "약 먹을 시간이야!" ② "아직 안 먹었지? 5분 지났어!" ③ "약속했잖아~" ④ 4회차부터 "N분째 기다리는 중…".
- 식별자 규칙: 배치 `{yyyyMMdd}-{slot}-{seq}`, 후속 `{yyyyMMdd}-{slot}-fu-{i}` → 슬롯 단위 일괄 취소.
- 인증 완료 시: pending + delivered 모두 해당 슬롯 전체 취소. 다른 슬롯 영향 없음.
- 사운드: 자체 합성 벨 아르페지오(`notification_chime.wav`).

### 5.4 사진 인증
- 진입: 홈 카드 버튼 / 알림 탭(해당 슬롯 카메라 직행, userInfo의 dayKey로 날짜 귀속).
- 흐름: 촬영 → 미리보기 → (Vision 판독) → 확정 → 저장/기록/알림취소 → 축하.
- **AI 소프트 게이트**: 약/복용 장면으로 보이면 통과, 애매하면 "약이 잘 안 보여요 🥺 다시 찍기 / 그래도 인증" 선택. 판독 실패는 통과(fail-open, 신뢰 기반). 오탐이 정직한 인증을 막지 않는 것이 원칙.
- 앨범 업로드 불가(실시간 촬영만).

### 5.5 슬롯 상태 머신
`disabled / waiting / soon(T−2h, 조기 인증) / dueNow(강조+wiggle) / completed(정시·지연 구분)`
- **조기 인증**: T−2h부터 조용한 "미리 인증하기" 버튼 (외출 전 미리 먹는 케이스).
- **지연 완료**: 완료 시점의 예정 시각 스냅샷(`scheduledAt`) 기준 +2h 초과 시 "늦어도 해냈어요! 💜" (설정 변경에 판정 불변).
- **자정 귀속**: 새벽 03시 이전 & 어제 저녁 미인증 → 홈에 "어제 저녁 약" 카드, 인증은 어제 날짜로 기록 (기획 v1 §10 구현).

### 5.6 홈
- 오늘 날짜 + 마스코트(상태 반응) + streak(하루 2회 모두 완료한 날만 카운트) + 슬롯 카드 2개 (+새벽엔 어제 저녁 카드).
- 알림 권한 꺼짐 시 상시 경고 배너(설정 앱 이동).
- 1분 틱으로 상태 자동 전환.

### 5.7 히스토리 (캘린더)
- 월간 뷰, 날짜별 하트 2개(채움=완료), 오늘 강조, 미래 비활성.
- 날짜 탭 → 상세 시트: 슬롯별 완료 시각(지연 표기 포함) + 인증 사진 크게.
- 월간 완료율 % (분모 = 경과일 × 2).
- 사후 수정 불가 — 정직한 기록.

### 5.8 위젯
- 잠금화면 원형(하트 2개) / 직사각형(슬롯별 상태+시간) / 홈 small(핑크 카드+streak).
- 앱 → App Group UserDefaults JSON 스냅샷 → 위젯. 상태 변화 시 즉시 갱신 + 30분 자체 갱신. dayKey 불일치(어제 데이터)는 미완료로 표시.

### 5.9 축하 화면
- 마스코트 폴짝 등장 + 파티클 40개 + 랜덤 칭찬 문구(8종).
- 2.8초 자동 복귀 + 탭 즉시 닫기. 햅틱 3연타.

### 5.10 인터랙션 공통
- 통통 버튼(BouncyButtonStyle)+햅틱, 등장 popIn, dueNow 카드 wiggle, 하트 버스트, 마스코트 숨쉬기/깜빡임/점프.
- Dynamic Type 지원(UIFontMetrics 기반 라운디드 폰트).

## 6. 데이터 모델 (실제 구현)

```swift
@Model final class MedicationRecord {
    var date: Date            // 항상 startOfDay로 정규화 (슬롯의 날짜)
    private(set) var slotRaw: String    // "morning" | "evening"
    private(set) var statusRaw: String  // "pending" | "completed"
    var completedAt: Date?
    var photoPath: String?    // Documents 기준 상대 경로
    var scheduledAt: Date?    // 완료 시점의 예정 시각 스냅샷 (지연 판정)
    var isLate: Bool          // completedAt > scheduledAt + 2h
}

@Model final class AppSettings {
    var morningHour/Minute: Int   // 기본 8:00
    var eveningHour/Minute: Int   // 기본 20:00
    var morningEnabled, eveningEnabled: Bool
}
```

## 7. 마스코트/브랜딩 시스템 (somsom 브랜치)

- `Branding.swift`: 앱 이름·캐릭터 이름 상수 (문구 화자 자동 반영).
- `CharacterView`: 애셋 이미지(`somsom_kkito_idle/waiting/happy`) 우선, 없으면 코드 드로잉 마스코트(핑핑이) 폴백. 애니메이션 동일 적용.
- 끼토 이미지는 작가 원본 시트에서 크롭(그림체 변형 0%). 시트는 `somsom_assets/` 보관.
- **아트 규칙**: 캐릭터를 텍스트 묘사로 재현 금지. 반드시 원본 시트를 이미지 입력으로 생성하거나 시트에서 직접 크롭.

## 8. 엣지 케이스 처리 표

| 상황 | 처리 |
|---|---|
| 슬롯 시각이 지난 시점에 설치/설정 | 당일 해당 슬롯 알림 없이 pending, 다음 회차부터 정상 |
| 자정 넘겨 인증 (새벽 ~03시) | 어제 저녁으로 귀속 (홈 카드 + 알림 dayKey 양쪽) |
| 1시간(12회) 무시 | 후속 알림 3개(+90/120/180분) → 이후 앱 열면 연장 |
| 일찍 먹는 날 | T−2h부터 조기 인증 |
| 아침 인증 ↔ 저녁 알림 | 식별자 네임스페이스 분리로 상호 영향 없음 |
| 알림 권한 거부 | 홈 상시 배너 → 설정 앱 유도. 온보딩 프라이밍으로 예방 |
| 카메라 불가(시뮬레이터) | 앨범 폴백 없이 안내 화면 (실촬영 원칙 유지) |
| 위젯에 어제 데이터 잔존 | dayKey 검증으로 미완료 표시 |

- **컬러**: 메인 핑크 `#FF8FC7` / 라이트핑크 `#FFE1F0` / 포인트 퍼플 `#C89AF5` / 크림 `#FFF8FB`.

## 12. 재작성 시 검토 포인트 (v2에서 유지 vs 재고)

**검증된 것 (유지 권장)**
- 반복 알림 배치+연장+후속 구조, 식별자 스킴, 순수 로직 분리(단위 테스트 22개).
- 소프트 게이트 사진 판독, 카메라 전용 원칙, 자정 귀속·조기 인증.
- 권한 프라이밍 온보딩, 질책 제로 카피, 슬롯 상태 머신.

**재고 후보 (새 버전에서 자유롭게 바꿀 것)**
- 화면 구조/비주얼 전체 — 현재는 "핑크 카드 3탭" 전형. 솜솜시티 세계관(도시? 마을? 캐릭터 관계)을 앱 구조 자체에 녹이는 방향 가능 (예: 캐릭터별 역할 — 라칠친 할머니가 히스토리 관리인, 북거씨가 시간 알림 담당 등).
- 마스코트 1인 체제 → 6캐릭터 앙상블.
- streak/보상 체계 — 수집·성장 요소(정원, 스티커북 등) 도입 여지.
- 홈 위젯/잠금화면의 시각 언어.
